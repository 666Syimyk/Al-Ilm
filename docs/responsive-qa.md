# Интерфейс и проверка Al-Ilm

Дата: 28 сентября 2026. Изменения локальные, не опубликованы на GitHub Pages.

## Что изменено

- Сохранена существующая зелёно-кремовая стилистика и персонажи. Финальные адаптивные правила загружаются после прежних слоёв CSS.
- Основные разделы на телефоне используют одну колонку и обычную прокрутку страницы; на широких экранах — сетки. Убраны принудительный горизонтальный режим, обрезание пояснений и конфликтующие фиксированные высоты.
- Нижнее меню учитывает безопасную область экрана. Кнопки получили минимальную высоту 44 px и видимый клавиатурный фокус; настройки имеют семантику диалога/переключателей, Escape, удержание фокуса и возврат фокуса после закрытия. Меню не перекрывает диалог.
- Исправлены сетки этапов буквы и карточек намаза, контраст игровых букв, перенос названий сур и фильтров, компактная карточка профиля.
- Убраны вымышленные минуты занятий и проценты языковых модулей. Показатели Корана относятся к соответствующей суре или дневной цели, награды имеют фактические критерии.
- Домашнее расписание обновляется из текущих координат, ежедневная миссия использует местную дату. Геолокация запрашивается только по кнопке.
- Учебный прогресс и настройки разделены по локальным профилям; прежние данные сохраняются при миграции. Повторные награды и обход существующего пароля кодом 0000 закрыты.
- Service worker не удаляет кэши посторонних приложений, обрабатывает офлайн-ошибки фонового обновления и не кэширует частичные Range-запросы аудио.

## Браузерная проверка

Проверено в Chrome с изменением viewport, а не на физических iOS/Android-устройствах. Тестовый origin `127.0.0.1:5174` отделён от профилей на `localhost`.

| Размер | Проверка |
| --- | --- |
| 320 × 740 | Главная, уроки, намаз, Коран, профиль, алфавит, список сур, поиск, таджвид, огласовки, словарь, грамматика, чтение, основы, выбор фона, приветствие, вход. Обнаруженные переполнения фильтров и приветствия исправлены. |
| 390 × 844 | Визуальный проход основных экранов; диалог профиля, возврат фокуса, игровые задания, настройки города. |
| 768 × 1024 | Семь основных экранов и урок буквы. Найден и исправлен конфликт grid-auto-flow списка этапов. |
| 844 × 390 | Главная в горизонтальной ориентации: страница прокручивается, блокирующей заставки поворота нет. |
| 1440 × 1000 | Главная и шесть ключевых экранов: сетки и отсутствие выхода содержимого за ширину экрана. |

Проверенные действия: открытие/закрытие настроек и Escape; переход первого задания буквы через зрительную проверку; пять правильных выборов в игре и переход к письму; поиск Алматы и появление расчётного расписания; запуск записи аята. Это выборочная проверка ключевых сценариев, а не утверждение о ручном прохождении каждой кнопки всех 114 сур.

## Автоматические проверки

Требуется Node **22.15+** (проверено на Node 24).

```sh
npm test
npm run validate:content
npm run verify:quran
npm run build
```

На момент проверки: 40 тестов проходят; контент-валидатор — 0 ошибок; точное сравнение — 6236/6236 аятов; production build успешен. Проверяются аккаунты/миграция/награды, весь обязательный путь уроков, отмена и ошибки аудио, часовые пояса/полночь, целостность источников и поведение service worker.

Сжатый Quran chunk уменьшен с исходных примерно 712 kB до 289 kB. Предупреждение Vite о размере несжатого Quran chunk остаётся. Старые большие слои CSS и PNG-иллюстрации требуют отдельной оптимизации; они не удалялись массово, чтобы не потерять существующий дизайн.

## Что нельзя обещать

- Проверка размеров в Chrome не заменяет испытания на физических телефонах, Safari, экранной клавиатуре, с реальными датчиками и слабой сетью. Полное соответствие WCAG не сертифицировано.
- Микрофон/компас и доставка системного уведомления устройством не проверялись с разрешениями пользователя. Закрытое приложение не имеет надёжного планировщика push.
- Это локальное приложение без серверной авторизации, синхронизации и резервной копии.
- Полная экспертная проверка религиозных пересказов не завершена. Русский перевод аятов скрыт, не все записи скачаны; сведения об источниках и правах см. в [content-verification.md](content-verification.md).
