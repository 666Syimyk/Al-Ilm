## Арабский текст Корана

В приложение загружен официальный **Tanzil Project, Uthmani 1.1**: 114 сур, 6236 аятов. Исходный файл сохранён без изменения в `src/data/sources/tanzil-uthmani.txt`; производный JSON содержит те же строки аятов, без нормализации символов. Буквы, огласовки, знаки и включение басмалы в первые строки следуют именно этому изданию.

- [Страница загрузки издателя](https://tanzil.net/download/)
- [Официальный файл](https://tanzil.net/pub/download/index.php?quranType=uthmani&outType=txt-2&agree=true)
- [Условия Tanzil](https://tanzil.net/docs/Text_License)
- Дата загрузки: `2026-09-28T07:24:34.683Z`.
- SHA-256 исходного файла: `bf4f57b968d03f4131c070b1e285da9be0e0a108a21c910e872801ca273312c8`.

Лицензия разрешает неизменённое копирование с атрибуцией, ссылкой и сохранением уведомления. Полное уведомление сохранено в TXT и JSON и доступно на экране источников. Ручной ввод или генерация коранических строк для нового корпуса не использовались.

`compareQuranText.mjs` теперь требует полный эталон и полный корпус приложения. Пустая загрузка, пропуск, дубликат, неверный номер или любое изменение строки приводят к ошибке; неизвестные отличия не объявляются «разницей кодировки». Онлайн-проверка 28 сентября сравнила все 6236 строк: 6236 точных совпадений, 0 отличий. Это совпадение с файлом издателя, не независимая проверка издателя.

Авторство, издание и разрешение на использование прежнего русского перевода не были установлены. Он не показывается в приложении, как и прежние пословные значения и транслитерация аятов. Старые ключи `russian_rwwad` и `russian_aboadel` отвечают на отдельные запросы, но не представлены в текущем каталоге; версия издания для установки не подтверждена. [Старая страница Russian Rwwad](https://old.quranenc.com/en/browse/russian_rwwad/1) помечена как работа в процессе. Это не основание выдавать такой набор за проверенный актуальный перевод. Для следующего выпуска нужен явно разрешённый, версионированный источник и редакционная проверка.

## Записи чтения

С [официального каталога EveryAyah](https://everyayah.com/recitations_ayat.html) скачаны **36 MP3** чтения Мишари Рашида Аль-Афаси, 128 kbps. Общий размер — **3 814 965 байт**. Это файлы записи, не синтез речи.

Локально доступны все аяты сур 1, 103, 108, 109, 112, 113, 114 (34 файла), а также 17:24 и 20:114. Последние две карточки дуа показывают полный аят, совпадающий с полной записью. Остальной Коран использует потоковые записи того же каталога, а не многогигабайтную локальную загрузку.

Для каждого файла `src/data/sources/recorded-audio.json` хранит точный URL, дату, размер, SHA-256 и MD5 издателя. При загрузке все файлы совпали с [официальным списком MD5](https://everyayah.com/data/Alafasy_128kbps/000_checksum.md5); валидатор повторно проверяет локальные байты. Проверка контейнера и хешей не является прослушиванием каждого аята специалистом.

Отдельная явная лицензия на дальнейшее распространение аудио на просмотренных страницах не найдена. Наличие открытой загрузки не означает public domain или разрешение коммерческого распространения. Перед публичным выпуском необходимо уточнить права у поставщика. Старые WAV-файлы без установленного происхождения не объявляются проверенными записями.

## Учебные разделы

- Шесть вопросов о столпах Ислама имеют конкретные ответы и ссылку на [Dar al-Ifta: The 5 Pillars of Islam](https://www.dar-alifta.org/en/article/details/65/the-5-pillars-of-islam). Общий фиктивный ответ для остальных тем убран.
- Семь карточек правовых терминов теперь содержат короткие пояснения по [словарю Dar al-Ifta](https://www.dar-alifta.org/en/article/details/111/shariah-law). Неподтверждённые примеры и тесты удалены. Это не фетва и не полный курс отдельного мазхаба.
- Таджвид остаётся учебным справочником для работы с учителем. Убраны неработающие «игры», универсальные тесты и выдача неизвестных WAV за образцы правил. Отметка изучения не является оценкой произношения.
- Для 99 имён и 25 историй пророков сняты неподтверждённые заявления о полной проверке. Наличие ссылки на аят и корректного номера не подтверждает все детали пересказа или толкования.
- После еды исправлена ссылка на [Бухари 5458](https://sunnah.com/bukhari:5458), краткая фраза прямо названа сокращением. Фраза перед сном сверена с [Бухари 6314](https://sunnah.com/bukhari:6314). Ссылка о начале еды — [Бухари 5376](https://sunnah.com/bukhari:5376).
- Сокращённая карточка выхода из дома скрыта до редакционной проверки: [страница Тирмизи 3426](https://sunnah.com/tirmidhi:3426) содержит разные оценки передачи. Приложение не разрешает это расхождение самостоятельно. Непроверенная формула еды в разделе чтения также скрыта; исходные записи сохранены в файлах данных.
- Коранические тексты в упражнениях чтения используют тот же точный корпус и соответствующие им записи, без прежних непроверенных переводов. Теперь отображаются 15 текстов для чтения и 6 ежедневных дуа.

## Намаз, время и кибла

- Порядок фард-намаза приведён к одному мазхабу (ханафитскому): сана, руки ниже пупка у мальчиков и на груди у девочек, ифтираш, подъём пальца на «ля иляха». Для девочек отдельные положения в такбире, руку, суджуде и сидении. Это упрощение для детей, требующее проверки имамом; в метаданных стоит `needsReview: true`.
- Коранические строки гида берутся из `src/data/prayerAyahs.js`; тест сверяет каждую строку с файлом Tanzil.
- Дуа перед салямом — Бухари 834, Муслим 2705.
- Время намаза: метод на выбор и ручная поправка ±30 минут для каждого намаза, чтобы совпасть с расписанием мечети. Компас киблы учитывает магнитное склонение (модель WMM 2025) и поворот экрана.

## Воспроизводимые проверки

```sh
node scripts/downloadVerifiedContent.mjs
node scripts/compareQuranText.mjs
node scripts/compareQuranText.mjs --online
node --test scripts/contentVerification.test.mjs
npm run validate:content
npm run build
```

Загрузчик запускается только вручную, не при сборке, и обновляет исходные файлы и манифест. Перед принятием обновления нужно проверить версию, условия и новый отчёт. Локальный валидатор проверяет структуру, полное покрытие, точное совпадение строк и хеши аудио; регулярные выражения по исходному коду не заменяют проверки браузерного воспроизведения.

## Что ещё требует работы

Построчная экспертная проверка историй, значений имён, таджвида, учебных переводов дуа и некоранических текстов намаза не завершена. Полного проверенного русского перевода аятов, пословного разбора, локальных записей всех сур и всех букв пока нет. Нельзя рекламировать приложение как полностью религиозно сертифицированное, полностью офлайн или автоматически оценивающее правильность чтения. Проверка права на публичное распространение записей также остаётся открытой.
